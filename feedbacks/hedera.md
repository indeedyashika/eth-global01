# Hedera

For context: first time ever building with Hedera

## The goods
- Was extremely easy to get testnet tokens + an address with the private key (https://portal.hedera.com/dashboard is great)
- Very impressed with the amount of documentation, tools, MCPs, playgrounds, contract builders... that the ecosystem has.

## The can improve
- Add in https://portal.hedera.com/dashboard more information of what all the different keys are - spent some time debugging because signatures did not match and it was the wrong format.
